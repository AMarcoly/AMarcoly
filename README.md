### 🎓 Background

- Master's in **Big Data (EID2)** at **Sorbonne Paris Nord** — class of 2026
- Data Engineer (graduation internship) at **Ecolab** (CGDD, French Ministry of Ecological Transition): territorial-indicators pipeline published on [ecologie.data.gouv.fr](https://ecologie.data.gouv.fr/indicators)

### 🔧 What I built at Ecolab

- **Extraction & orchestration**: data collectors and Airflow DAGs, from source to automated open-data publication
- **Quality**: ~60 automated tests (pytest) on the pipeline, data-quality alerting module, lineage tracking
- **CI/CD**: the project's GitLab CI chain, containerized dbt runs on Kubernetes
- **End to end**: Ecosystems domain delivered from dbt transformation to API exposure (CubeJS)

### 🌱 Open source contributions ([`ecolabdata`](https://github.com/ecolabdata) organization)

- **[PR #91 — ecospheres-dashboard-backend](https://github.com/ecolabdata/ecospheres-dashboard-backend/pull/91)**: fixed a non-additive metrics aggregation bug (unique visitors, bounce rate) — monthly stats cannot be summed from daily rows
- **[PR #27 — secateur](https://github.com/ecolabdata/secateur/pull/27)**: code-quality audit of a QGIS plugin — pytest-qgis test suite, docstrings, dependency graph, dead-code removal
